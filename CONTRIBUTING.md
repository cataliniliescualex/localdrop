# Contributing

Thank you for your interest in LocalDrop!

1. Search existing issues before opening a new one.
2. Reproduce bugs on the latest release; include OS, browser, steps and sanitized diagnostic logs. Never disclose pairing PINs, authentication tokens or private file paths.
3. For changes, open an issue to discuss first, then propose a focused pull request with tests.
4. Run `python3 -m unittest -v test_localdrop.py` before submitting.
5. By submitting a contribution, you agree to license your contribution under MPL-2.0 while keeping your copyright unless otherwise arranged. Do not submit code you lack permission to share.

Commercial extensions may live in separate repositories and are not automatically part of the open-source core.
